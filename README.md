# Americano — бот заказов и автоматической лояльности

Готовый Telegram-бот для сети из **трёх кофеен Americano**.

## Как работает лояльность

- Баланс клиента единый для всех трёх филиалов.
- Учитываются все позиции с `is_coffee: true`.
- После отправки заказа бот сам определяет количество кофе.
- Кассиру не нужно нажимать «подтвердить», начислять баллы или считать остаток.
- Каждый шестой кофе автоматически становится бесплатным.
- Бот сам уменьшает стоимость заказа на цену подарочного кофе.
- Если в заказе несколько видов кофе, в подарок списывается самый дешёвый кофейный напиток.
- После подарка цикл начинается заново автоматически.

Пример:

- после 1-го кофе осталось 5;
- после 4-го осталось 2;
- после 5-го бот сообщает, что следующий кофе бесплатный;
- 6-й кофе становится подарком;
- после этого новый цикл начинается с нуля.

## Три филиала

В `index.html` уже добавлен обязательный выбор:

- Americano — Филиал 1;
- Americano — Филиал 2;
- Americano — Филиал 3.

Замените эти названия на реальные адреса филиалов в элементе `<select id="branch">`.

Команда администратора `/stats` показывает общую статистику и статистику отдельно по каждому филиалу.

## Файлы

- `bot.py` — Telegram-бот, SQLite и автоматическая логика лояльности.
- `index.html` — меню Telegram WebApp.
- `requirements.txt` — зависимости Python.
- `Procfile` и `runtime.txt` — запуск на хостинге.

## Переменные окружения

```env
BOT_TOKEN=токен_бота
ADMIN_IDS=6013591658
WEBAPP_URL=https://tahirovdd-lang.github.io/Cafe-Americano/
DB_PATH=/app/data/americano.db
```

Для нескольких получателей заказов:

```env
ADMIN_IDS=6013591658,123456789,987654321
```

## Запуск

```bash
pip install -r requirements.txt
python bot.py
```

## Добавление кофе

В массиве `PRODUCTS` у каждого кофейного напитка должны быть параметры:

```js
cat: 'coffee',
is_coffee: true
```

Для чая, лимонадов, десертов и других товаров:

```js
is_coffee: false
```

## Важно для реальной работы

Автоматическое начисление происходит при отправке заказа из Telegram WebApp. Поэтому меню должно быть единственным рабочим каналом оформления заказов по этой программе лояльности. Для интеграции с кассовой системой начисление лучше вызывать после успешной оплаты через API кассы.
